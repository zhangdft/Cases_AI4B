# AI4Bat 课程案例库 (Cases_AI4B)

本仓库包含了“人工智能在电池研发中的应用 (AI4Bat)”课程的所有实践案例，旨在引导学生了解利用 AI 相关技术加速电池研发效率的概念。

## 案例目录

### [Case 1: 机器学习入门 —— 薪资预测实战 (Salary Prediction)](Case_1/)
- **内容**：通过一个简单的 ML 模型训练，介绍数据探索、特征工程、模型对比及解释。
- **目标**：建立机器学习的基本工作流概念。

### [Case 2: 材料研发的三大范式 —— 以电池抗枝晶材料设计为例](Case_2/)
- **内容**：以剪切模量预测为案例，对比实验试错、计算指引 (DFT) 和 ML 辅助三种范式。
- **重点**：
  - **DFT 计算**：以 LiF 为例的第一性原理计算流程。
  - **ML 优化**：多模型对比、特征去冗余、高通量筛选思路。
- **目标**：理解 AI 如何与传统物理计算结合，加速材料筛选。

### [Case 3: GNN 入门 —— 基于 CGCNN 的晶体剪切模量预测](Case_3/)
- **内容**：在 Case 2 的基础上，引入图神经网络 (GNN) 表征晶体结构，完成剪切模量预测；包含 CGCNN 预训练模型微调与从头构建的简单 GNN 示例。
- **重点**：
  - **晶体图表示**：原子/近邻关系 → 图结构输入
  - **迁移学习**：加载 CGCNN 预训练权重进行微调
  - **模型评估**：预测-真实值关系、MAE、$R^2$、训练曲线
- **目标**：理解材料性质预测从“特征工程”到“结构表示学习”的转变。

### [Case 4: 生成式设计入门 —— 基于 VAE 的电解液溶剂隐空间探索](Case_4/)
- **内容**：使用 Fingerprint + VAE 学习电解液溶剂分子的连续隐空间，并进行可视化、相似分子搜索与隐空间插值探索。
- **重点**：
  - **分子表示**：SMILES → Morgan/ECFP 指纹
  - **生成式模型**：VAE 的 encoder/decoder、重构损失与 KL 散度
  - **隐空间分析**：PCA/t-SNE/VAE latent 对比、最近邻、插值路径探索
- **目标**：建立“生成式模型用于空间探索与候选筛选”的基本直觉。

- `numpy`, `pandas`, `matplotlib`, `seaborn`
- `scikit-learn`, `xgboost`
- `matminer` (用于 Case 2)
- `pytorch`, `pymatgen` (用于 Case 3)
- `rdkit`, `pytorch` (用于 Case 4)
